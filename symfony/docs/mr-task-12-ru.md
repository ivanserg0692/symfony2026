## Планируемый объём

- Развить frontend из Task 6: каталог, карточка товара, поиск, доступные API фильтры, сортировка и пагинация для покупателей.
- Интегрировать корзину, оформление заказа и просмотр собственных заказов через существующий Symfony API Gateway `/api/v1`.
- Соблюдать действующие контракты авторизации и валидации, отображать состояния загрузки, отсутствия данных и ошибки API.
- Подготовить адаптивный интерфейс и единое оформление светлой и тёмной тем с сохранением выбора пользователя.
- Описать подключение к API и проверку пользовательских сценариев в frontend-репозитории.

## План проверки

- Пройти путь от каталога до заказа с существующим Symfony API.
- Проверить поиск, фильтрацию, пагинацию, изменение корзины, авторизацию и ошибки валидации API.
- Повторить основные сценарии в обеих темах и проверить сохранение выбора после перезагрузки.
- Проверить мобильный и настольный интерфейс, навигацию с клавиатуры, пустые состояния и недоступность API.
- Добавлять фактические результаты реализации и проверок новыми датированными разделами после исходного плана.

## Вне задачи

- Реализация frontend или backend в текущем изменении документации.
- Неявное изменение API-контрактов, прямой доступ фронтенда к базам данных, Elasticsearch или внутреннему gRPC.
- Платёжные интеграции, доставка и административный интерфейс.
- Утверждение о завершении реализации или успешных проверках до выполнения соответствующей работы.
